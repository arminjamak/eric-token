# Plain Loop

_Say only what moves, what causes what, and when._

## Core words

| word | meaning |
|---|---|
| `to` | moves, flows or is sent to. Chains: A to B to C. |
| `back to` | returns to an earlier step (rework or repeat). |
| `then` | next step starts only after the previous step finishes. |
| `split` | the paths listed after it run in parallel, at the same time. |
| `both done` | join: wait until every parallel path finishes (use all done for 3 or more). |
| `after` | delay or count before the next thing: after 2 weeks, after 3 failures. |
| `stock` | an amount that builds up over time; inflow raises it, outflow lowers it. |
| `reinforcing loop` | a loop that amplifies its own change: growth feeds more growth. |
| `balancing loop` | a loop that pulls back toward a target or limit. |

## Rules

1. Comparative pairs show cause: more A, more B means more A causes more B. Any comparative works: less, higher, slower.
   - e.g. `more rain, higher river`
   - reads as: more rain causes a higher river

2. A cause chain followed by a colon and a loop type feeds back to its first item. Types: reinforcing loop, balancing loop. Standing alone as a statement, it names the loop just described.
   - e.g. `more sales, more ads: reinforcing loop`
   - reads as: more sales bring more ads, which bring more sales; self-amplifying

3. Conditions: if C, X. Use else for the other case. Semicolons separate branches. Compare with over, below, at.
   - e.g. `if level over 80, alarm; else wait`
   - reads as: if the level exceeds 80 the alarm sounds, otherwise keep waiting

4. A colon introduces parts or details of the word before it. A system has subsystems: list them.
   - e.g. `city has districts: north, south`
   - reads as: the city is a system with two subsystems, north and south

5. Drop articles and filler words. Every other word keeps its plain English meaning.
   - e.g. `check each order`
   - reads as: each order is checked

6. Commas list steps or effects in the order they happen. A period ends one statement.
   - e.g. `if cold, heater on, raises heat`
   - reads as: when cold, the heater turns on and raises the heat

Any other English word is an ordinary content word (a thing, quantity, actor or action) with its usual meaning.
