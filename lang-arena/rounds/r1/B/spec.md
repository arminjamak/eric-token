# Terse

_Systems said in the fewest literal words._

## Core words

| word | meaning |
|---|---|
| `lift` | A lift B: more A causes more B, less A causes less B |
| `cut` | A cut B: more A causes less B, less A causes more B |
| `grows` | the loop just named reinforces itself, self-amplifying |
| `seeks` | balancing loop: pulls toward its goal and settles there |
| `vs` | is compared with |
| `then` | next step starts only after every previous step finishes |
| `to` | moves or flows to; A to B to C is a path |
| `back` | flows back to an earlier step, a rework loop |
| `lag` | lag N: arrives only after a delay of N |
| `stock` | X stock: X is an amount that accumulates over time |
| `in` | inflow into the stock; out is outflow from it |
| `has` | system has subsystems, listed with commas |
| `split` | split A, B: A and B run in parallel at once |

## Rules

1. X: Y means when X holds, Y happens; else Z is the other case. Semicolons separate clauses; commas list items or steps. Bare verbs are actions.
   - e.g. `valid: process, else reject; 3 fails: stop`
   - reads as: if valid, process it, otherwise reject it; after three failures, stop

2. A chain that ends on its first word is a closed loop.
   - e.g. `cats lift kits lift cats, grows`
   - reads as: more cats, more kittens, more cats: a reinforcing loop

Any other English word is an ordinary content word (a thing, quantity, actor or action) with its usual meaning.
